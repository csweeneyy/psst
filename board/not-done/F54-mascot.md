# F54 - Mascot and customisation

**Why**
The user's idea: a bird or digital pet that is both the app mascot and the
thing points are spent on. This is also the "rebranding" wanted for the top of
the Home screen, currently a placeholder "Today".

**The risk, stated plainly**
This is the single highest-risk item on the board. A mascot done badly drags
the whole app down with it, and the app currently reads as a serious, native,
Apple-adjacent tool. A cute animal is a hard tonal swerve from near-black
graphite and SF Pro. Done well it is memorable and gives points a purpose;
done at speed with generated art it looks like a different, worse app.

**What would make it work**
- Vector, monochrome or two-tone, in the same near-black. Not an illustration.
- Reactive rather than decorative: posture changes with the streak, slumps
  when a habit is missed. State the user caused, not a sticker.
- Points buy small, tasteful variations. No hats.
- Lives on the Home header where "Today" is now, at a size that does not
  dominate the list below it.

**Prerequisite**
Points exist now (F15), so there is something to spend. The blocker is art
direction, not engineering.

**Status**
Not started. Needs a decision on tone before any code. Worth a real designer
or a deliberate art pass, not a rushed one.
